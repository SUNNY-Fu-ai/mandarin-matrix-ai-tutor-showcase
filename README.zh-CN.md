## 我的工作

我参与教学与产品需求梳理、系统架构方案、教材资源的 AI 流程整理、实时语音与动态头像的集成、交互界面原型、测试，以及根据客户反馈修改演示。

开发使用了 AI 辅助编码与建模工具。我的职责包括设定要求、组织工作流程、检查产物和解决集成问题。原角色设计、插画和教学内容由 Mandarin Matrix 提供。
