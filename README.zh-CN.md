## 我的工作

- 设计语音驱动数字人架构并组织开发流程。
- 将 Mark 适配为 3D，开展表情、动画和口型同步工作。
- 整理教材资源，接入课程与对话流程。
- 集成实时语音交互并开发原型界面。
- 根据公司和中文教师的反馈改进教学流程与交互。

开发使用了 AI 辅助编码与建模工具，我负责设定要求、组织工具工作、检查结果和解决集成问题。原角色、插画和教学内容由 Mandarin Matrix 提供。当前产品介绍中使用的语音技术为 xAI 的 Grok。
